# RAGAS Evaluation Results

This file is generated by the evaluation harness. Run it locally with Ollama
running (the environment used to build this project had no Ollama instance, so
the table below is a template to be filled by an actual run):

```bash
ollama serve                 # in a separate terminal
ollama pull qwen2.5:3b       # or a larger EVAL_LLM_MODEL for better judging
python scripts/make_sample_docs.py   # once, to (re)generate sample PDFs
python -m src.evaluation
```

The harness evaluates the 22 Q&A pairs in `data/eval/qa_dataset.json` against
the sample GreenLeaf corpus, using a fully local judge (the Ollama model + the
`bge-small-en-v1.5` embeddings). No data leaves the machine.

| Metric | Score (0-1) | What it measures |
|--------|-------------|------------------|
| faithfulness | _run to fill_ | Answer claims grounded in retrieved context (higher = less hallucination) |
| answer_relevancy | _run to fill_ | How directly the answer addresses the question |
| context_precision | _run to fill_ | Whether relevant chunks are ranked highly |
| context_recall | _run to fill_ | Whether all needed info was retrieved |

> Scores from a small local judge (e.g. `qwen2.5:3b`) are directional. Set
> `EVAL_LLM_MODEL` to a larger local model for more reliable judging.

## Retrieval upgrade (informal, Phase 1)

Before/after the Phase 1 retrieval upgrade (semantic chunking + hybrid BM25 +
dense search + cross-encoder reranking), verified on the sample corpus:

- Query "What is the warranty on the SunMax 400 panel?" -> top reranked chunk is
  the SunMax 400 product guide.
- Query "How many employees does GreenLeaf have?" -> top reranked chunk is the
  company overview document.

The cross-encoder reranker reliably promotes the single correct source document
to rank 1 across the sample questions.
